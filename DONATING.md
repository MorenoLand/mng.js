# Donating

Support is optional, and there is no sponsorship requirement or paid support program for this project.

Official donation page: [ko-fi.com/denveous](https://ko-fi.com/denveous)

The most useful donation is time: preserve MNG support, add an implementation, improve a fixture, test an older runtime, or document how to use it.

Do not send money to an account claiming to represent this project unless it is listed in this file.
